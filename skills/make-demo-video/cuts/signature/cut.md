# 招牌片（signature）

每次由 Claude 從零設計一支動態設計片：一個概念貫穿到底，每個畫面都由前一個變形而來，沒有硬切、沒有淡入淡出。片長以小節計（120 BPM，一拍 0.5 秒、一小節 2 秒），配樂、動態模糊，最後一格回到第一格可以循環。

跟其他剪法不同：其他剪法只能組合現有的鏡頭模板，招牌片是**生成式**的，畫面由 Claude 寫成一份 `reel.html`。所以概念與畫面每次都不同；能固定下來的是腳本（② 鎖住）與定稿後的 `reel.html`（之後改字、重出都從這份改）。

## 腳本（② 沒有備好腳本時）

寫 6–8 句，順序固定，每句都是之後畫面上會出現的字（**畫面上只能出現腳本裡的字**，檢查會擋）：

1. **開場（1 句）**：產品名。中文名 6 字以內；英文名照原樣寫，不要翻譯或縮寫。
2. **問句（2–3 句）**：使用者打開這個產品前心裡在問的問題，每句 12 字以內，結尾問號。
3. **答案（1 句）**：一句話回答，帶出產品名。
4. **數字（0–2 句）**：素材裡讀得到的數字，一句一個（「1,534 個地點」）。README、網站文案，或程式碼裡能直接數出來的都算，出處寫進 `beats.md`。**沒有就跳過，不要編。**
5. **收尾（1 句）**：標語。產品名在片尾會再出現一次，不用另寫一句。

網址這類不是句子的字，寫在 `SIGNATURE.extra`。

## 概念（③ 開始時）

先給使用者三個概念選，每個一行，格式是「A 變成 B 變成 C」，A 是第一格，最後要回到 A（例如「一個點，長成一頓飯」「問號下面的點，長成整座城市」）。概念要從產品本身長出來（地圖釘、聊天泡泡、溫度計），不要用跟產品無關的抽象圖形。

- 有 `show_concepts` 工具時用它把三個概念放到面板上（面板會加「你來決定」與自己寫的欄位），然後結束這一回合；沒有時用 AskUserQuestion 問三個概念加「你來決定」；都沒辦法問時選第一個，回覆裡說選了哪個。
- 選定後寫 `<out>/beats.md`：第一行是概念，下面是逐拍分鏡表（拍、秒、畫面、對到腳本第幾句、技法）。

## 逐拍

照原提示詞的結構，15 秒是 7.5 小節：

| 小節 | 秒 | 內容 |
|---|---|---|
| 1 | 0–2 | 開場：產品名，從第一格的形狀長出來 |
| 2–6 | 2–12 | 一小節一種技法，順序自訂：**動態文字**（問句）、**形狀變形**、**2D 轉 3D**、**數據或介面**（數字、截圖）、答案；每種佔一樣長 |
| 7 | 12–14 | 全片最強的一刻：上升音從 10 秒爬到 12 秒，在這小節的第一拍落下重拍 |
| 7.5 | 14–15 | 片尾：產品名＋標語，最後半拍收回第一格 |

- **每拍都要有事發生**：拍頭與拍尾不能一模一樣（檢查會擋）。
- 一般畫面停留不超過半拍；**關鍵句例外**：答案、數字、片尾完整出現後至少停 0.5 秒，停的時候慢慢推近或漂移，不要完全靜止。關鍵句與它完整出現的時間寫進 `SIGNATURE.lines`。
- 30 秒版本就是 15 小節：每種技法兩小節，其他照比例拉長。
- 有截圖時放在「數據或介面」那小節：用遮罩、傾斜、裁切把它變成同一種畫面語言，不要整張平貼。截圖上的字不受「只能出現腳本的字」限制。

## 做法

1. 複製 `<skill>/cuts/signature/kit.html` 成 `<out>/reel.html`，只改 `SIGNATURE`、「元素」、`seek` 三段；工具函式（`eo`、`spring`、`circle`/`roundRect`/`mix` 變形、`actor` 自動動態模糊、`renderAudio` 配樂）照用。尺寸：9:16 是 720×1280、16:9 是 1280×720、1:1 是 1080×1080。
2. 一套字型（要有繁中字），最多三個顏色加黑白，顏色取自素材；一種鏡頭語言（例如只有垂直移動與前後傾）。
3. 每一格都只由 t 決定：`seek(t)` 每次把每個元素的樣式重算一遍。不用 CSS 動畫、transition、計時器、`Math.random`（用 `rng(seed)`）。
4. 緩動只用指數（`eo`、`ei`、`eio`）與不回彈的彈簧（`spring`）；快速移動用 `actor` 讓模糊跟著速度與方向。
5. 配樂用骨架的 `renderAudio`：每拍大鼓、每小節換場一記重拍、上升音進最後一整小節；可以加低音與拍間高音，落點不改。
6. **禁止**：粒子爆炸、光暈、鏡頭光斑、畫面晃動、RGB 分離、交叉淡化、通用漸層、彈跳緩動、看起來像模板的東西。

## 檢查與修改

```bash
node <skill>/scripts/signature.mjs beats <out>/reel.html
```

會檢查：沒有 CSS 動畫與計時器、`SIGNATURE` 齊全、畫面上的字都在 script.md、關鍵句停夠且從 from 到 to 都整句看得到、每拍都有動作、位置或路徑沒有算成 NaN、最後一格等於第一格；並在 `<out>/beats/` 存每拍一張縮圖、`<out>/beats-sheet.png` 一張總表。

1. 檢查沒過先自己修，過了再**自己看一次 beats-sheet.png**：太擠、重疊、壓到邊、看不清楚的拍子先修。
2. 給使用者看逐拍縮圖：有面板時面板會自己讀 `beats/beats.json` 畫逐拍分鏡板，使用者在某一拍按 ✎ 會送來「改第 N 拍（t 秒）：…」；沒有面板時在對話裡給 beats-sheet.png（每格左上角有拍號與秒數），問要改哪幾拍。**只改那幾拍的程式**，不動其他拍；改完重跑 `beats`。
3. 使用者按「合成影片」或說可以了才算圖：

```bash
node <skill>/scripts/signature.mjs render <out>/reel.html
```

60fps、每格 3 個子格平均成動態模糊、配樂一起混進去，輸出 `<out>/demo.mp4`、`demo.gif` 與結果頁 `demo.html`（標題取腳本第一句、顏色取 `COL`、網址取 `SIGNATURE.extra`），並打開結果頁。15 秒約 1.5 分鐘。
