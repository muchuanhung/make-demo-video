# 快節奏導覽（fast-tour）

標語開場 → 名字出場 → 一項一項快切 → 手機在網站上捲到每句話的證據 → 重點色收尾。一拍 0.4 秒，平均一幕 1–2 秒，看起來像社群上的產品短片。

快不是趕：**每一幕只講一件事，字少到一眼讀完**，節奏才快得起來。字一多，要嘛還沒讀完就轉場，要嘛只能把那一幕拉長，兩種都不是快節奏。

這份檔案只管「怎麼剪」：腳本怎麼寫、每句配哪個鏡頭、拍數怎麼分。鏡頭模板能做什麼、欄位怎麼填，看 SKILL.md 的鏡頭表與「分鏡表格式」。

## 腳本（② 沒有備好腳本時）

從素材寫 6–10 句短句（一句就是一個 1–2 秒的鏡頭）：

- 第一句是「看的人得到什麼」，不是產品名稱；影片上會分兩行顯示（例如「把想法／做成真的。」）。`script.md` 裡一句一行、不寫換行符號，換行只在 ③ 分鏡的 `heading` 裡用 `\n` 加。
- 每句 12 字以內（最多 16 字），影片上要能一眼讀完；名字、作品名、功能名可以單獨成一句。
- 一句只講一件事：「選方案、預約、到店，三步完成」是三件事，改成「三步完成預約」，細節交給手機畫面去證明。
- 作品、功能、方案這類清單，**每一項各一句**（之後各給一張作品卡），不要合成一句。
- 每一句都要有畫面能證明它：說到某一頁的內容，那一頁就要截圖；說到狀態切換（深色／淺色、修改前後），兩個狀態都要截圖。

兩種可選段落，素材有才加，放在名字出場之後、功能之前：

- **問句（2–3 句）**：使用者打開這個產品前心裡在問的問題，同一個句型只換最後的關鍵字（「早午餐吃哪？」「約會去哪？」「宵夜吃什麼？」），每句 12 字以內、結尾問號，後面接一句帶出產品名的答案。問題要對得上產品真的能解決的事；產品只解決一件事時不要硬湊。
- **數字（0–2 句）**：素材裡讀得到的數字，一句一個（「1,534 個地點」「4.8 分好評」）。README、網站文案，或程式碼裡能直接數出來的都算。**沒有就跳過，不要編、不要估。**

## 鏡頭順序（③）

典型的一支：`hook → intro →（問句 card × N → 答案）→（stat）→ card × N → toggle → feature → content → cta → outro`。沒有的素材就跳過那一段（沒有深色模式就不排 toggle、沒有文章就不排 content），不要硬湊。

- 第一句一定是 `hook`，最後一句一定是 `outro`。
- 名字、產品名第一次出現用 `intro`。
- 問句用 `card`（`icon` 放一個代表這個問題的 emoji，`label` 寫 `Q1`、`Q2`…，不寫 `kicker`）；答案有截圖時用 `intro` 或 `feature`，沒有時用 `hook`。
- 數字用 `stat`：`value` 寫數字原樣（`1,534`、`6,000+`、`96.8%`），`heading` 寫說明（「個地點」）；百分比、評分這類接近上限的數字，`start` 設成一半左右，跳起來比較有感。
- 作品卡只給「真的是一項一項的清單」用；沒有畫面也講得清楚的項目才用 `card`。
- **只有一張長圖時**（單頁網站）：每一句都用手機鏡頭、捲到截圖上講這件事的那段（`to` 寫那段的標題或標籤），模板之間輪流換（intro → feature → content → cta），不要為了避開同一張圖而把功能改成作品卡。單頁網站沒有號召行動時，`cta` 給最後一個功能當特寫。

## 相鄰兩幕要不一樣

- 同一個模板不連用 3 次。
- 相鄰兩個手機鏡頭不要用同一張截圖捲到同一段（單頁網站用同一張長圖沒關係，捲到不同段落就好；兩段太近時換 `layout`）。

## 一幕只講一件事（③）

- 標題是整句話時（功能、步驟、問題），**小標和標籤擇一或都不放**；畫面上的手機截圖已經在補充細節。
- 名字、作品名這種短標題（6 字以內），才配小標＋技術標籤當點綴（例如「曉行 Dawnline」配 GPX、Next.js）。
- 標籤最多 3–5 個、每個 1–3 字，不要重複標題裡已經有的字。
- 自動檢查會擋：標題超過 16 字，或標題加小標、標籤超過 16 字。

## 拍數

- `beat` 用 0.4 秒一拍，各模板的預設拍數見 SKILL.md 的鏡頭表。
- 總拍數 × 0.4 ≈ ① 選的秒數（差 3 秒以內，寧短勿長）。
- 預設拍數加起來太長時，先從 intro、feature、content 減（最少 3 拍）；hook、card 不要少於 3 拍，`stat` 不要少於 4 拍（數字跳完要 1 秒，再停 0.5 秒），outro 不要少於 4 拍（結尾要讓人看清楚網址）。太長時先拿掉一個問句，再拿掉一句數字。
- 停留時間照字數算（12 字約 0.72 秒，字少至少 0.5 秒），檢查說「加 N 拍」就加；加了會讓總長或平均超標時，**先刪字**，不要硬塞。
- 使用者在面板上自己調過的拍數不要改回去（超過 3 秒的提醒是使用者的選擇）。
